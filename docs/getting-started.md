# Getting Started

## 5-minute setup

1. Install dependencies: `npm install`
2. Build all packages: `npm run build`
3. Run tests: `npm test`
4. Initialize local CLI vault: `node cli/dist/index.js init`

## DPDP Act compliance checklist

- [x] Encrypt personal data at rest (L3)
- [x] Log sensitive access events (L5)
- [x] Protect AI interactions with PII redaction (L4)
- [x] Verify access with identity and RBAC (L2)
- [x] Enforce perimeter controls and abuse resistance (L1)
